# Harmonix on AWS

Harmonix was a developer experience solution that simplified the use and consumption of AWS services while minimizing required expertise in cloud infrastructure technologies. Built on the [Backstage open platform](https://backstage.io), this solution provided customizable software templates, scaffolder actions, and deployment patterns.

**Latest Release**: [v0.4.2](https://github.com/awslabs/harmonix/releases/tag/v0.4.2) - Contains critical security fixes
