This project is deprecated and partnerships are no longer active. The information below is preserved for historical reference.

Previous Collaborations​

During its active development, Harmonix on AWS collaborated with several teams and initiatives:

AWS Cloud Foundations Team (Historical)​

The Cloud Foundations Team, in collaboration with the Central Area Greenfield SA Team, introduced a flexible and scalable program to expedite a customer's progress in establishing their cloud foundation. Cloud Foundations Accelerator (CFA) was comprised of various modules that were specifically tailored to build a customer's core cloud foundation in accordance with Cloud Foundations best practices.

Cloud Foundations


CNOE (Historical)​

Harmonix on AWS participated in the Cloud Native Operational Excellence (CNOE) framework, which brought together enterprises operating at scale to navigate operational technology decisions together.

The CNOE framework brought together a cohort of enterprises operating at the same scale so that they could navigate their operational technology decisions together, de-risk their tooling bets, coordinate contribution, and offer guidance to large enterprises on which CNCF technologies to use together to achieve the best cloud efficiencies.

CNOE.io

Data on EKS (Historical)​

Harmonix on AWS collaborated with Data on Amazon EKS (DoEKS) - A tool for building AWS managed and self-managed scalable Kubernetes data platforms on Amazon EKS.

Data on EKS
