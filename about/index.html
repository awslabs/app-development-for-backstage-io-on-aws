About Harmonix on AWS

Project Status: Deprecated

Harmonix on AWS is no longer actively maintained as of December 2025.

This project served as a reference implementation and should not be used for production environments. The information below is preserved for historical reference and to acknowledge the contributions of those who worked on this project.

What Harmonix on AWS Was​

Harmonix on AWS was a reference implementation that brought AWS cloud closer to developers. The platform allowed enterprises to build environments and applications on AWS without requiring developers to upskill on cloud expertise. Harmonix on AWS provided a reference implementation for an enterprise-grade fully integrated platform, improving the developer experience with a secure and scalable solution for non-cloud developers.

Based on Backstage, which is an open-source platform enabling a well-built and well-designed user interface, Harmonix on AWS leveraged the Backstage ecosystem. The Backstage platform itself has been adopted by over 900 companies as their primary developer portal and has over 100 plugins available for its end users. Harmonix on AWS took Backstage to the next level by seamlessly integrating it with AWS and packaging it together for enterprise use.


FSI PACE Platform Engineering Team​

The FSI PACE Platform engineering team was focused on unblocking customers and accelerating their journey to the cloud. While working with different customers in the financial services industry, the team identified common challenges around landing zones, lack of cloud skills, and difficulties building internal developer platforms. Many customers were trying to build internal solutions or found themselves paying hefty fees for external services. Along with customers, the team embarked on this journey of simplifying the internal AWS experience, which led to the creation of Harmonix on AWS.
